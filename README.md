# Cuddly Viewer: Autonomous AI Merchandising

Cuddly Viewer is a spatial showroom that bridges the gap between cultural AI and 3D physics. It allows a user to type in any brand name (e.g., "Gucci", "Nike", "Balenciaga").

Instead of just generating a 2D image, the app:
* Queries the Qloo Taste Graph to extract the brand's exact cultural DNA, lifestyle tags, and affinities.
* Feeds that data into Gemini to calculate physical PBR (Physically Based Rendering) properties.
* Instantly morphs a 3D web garment in real-time—changing its fit proportions, fabric weave (silk vs. fleece), sheen, color, and drape to perfectly match the brand's identity.
* Features a robust AI fallback mechanism for low-latency brand processing and an immersive offline mode for cached visual rendering.
